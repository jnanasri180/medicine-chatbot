# 🧑‍⚕️ AI Medicine Recommendation Chatbot

An AI-powered multilingual medicine recommendation chatbot built using Streamlit, Python, Google Translate, and gTTS.  
The chatbot suggests medicines based on symptoms entered by the user and provides translated voice responses.

---

## 🚀 Features

- 💬 Interactive chatbot UI using Streamlit
- 🌍 Multilingual support (English, Hindi, Telugu, Tamil)
- 🔊 Voice output using gTTS
- 🌐 Language translation using Google Translate
- 💊 Medicine suggestions based on symptoms
- 📜 Chat history sidebar
- ⚡ Real-time response generation

---

## 🛠️ Technologies Used

- Python
- Streamlit
- gTTS
- Googletrans
- JSON
